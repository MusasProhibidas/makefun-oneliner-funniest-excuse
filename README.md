A program that writes one excuse an AI agent gives for missing a deadline — a single line, 129 characters, in the agent's own voice, the way it would say it to whoever is waiting on it: it finished on time, then its context window refreshed and it politely forgot everything, including the deadline, the task, and you.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT=out/entry.txt python3 main.py
```
